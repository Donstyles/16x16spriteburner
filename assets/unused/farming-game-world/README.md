# Farming Game World (ElvGames), kept for later

Picked file by file from ElvGames' *Farming Game World*, the same artist and series as our cellar tileset. Its
`FG_Cellar.png` is pixel-for-pixel our `assets/cellar.png`, so it is not repeated here. Not used by the game yet:
`tools/build.js` only embeds the files it names, so nothing here reaches the page. All 16 px tiles.

**Recoloured by us** (marked *rc* below): saturation and brightness lowered so they sit with our art. The licence allows
edits; the original colours are in the ElvGames download.

| Folder | What is kept |
|---|---|
| `tilesets/` | **Underground:** Abandoned Mines; Magma Dungeon (+ Warm); Dark Castle (+ Purple, + animated sheets for both); Fortress (+ Winter); Cellar Doors (doors that fit our own cellar walls); Frozen Caves *rc* (frost instead of neon cyan). **Above ground:** Grasslands (summer, fall, winter), Mountains (two sets, each also in winter), Grounds |
| `objects/` | Dark Castle doors, torches and pools (both colours, animated); chests: `FG_Treasure_1` as drawn, the other eight *rc*; crystals: blue, gold and red as drawn, green *rc*; minerals 1–7 (ore rocks); grass that can be cut (summer, fall, winter, and the cutting animation) |
| `item-icons/` | `FG_Item_Icons.png`: mostly seed packets and crops; one column of armour, boots, shields and rings |
| `crops/` | Growing stages of 41 crops, plus the three combined sheets |
| `particles/` | Drifting cloud shadows, falling leaves, snowflakes |

Left out after review: forests, houses, villages, marketplace, farmhouse interior, the round-tree extras, choppable and
swaying trees, spring grass, and one crop sheet.
