# Farming Game World (ElvGames), kept for later

The full *Farming Game World* bundle from ElvGames, the same artist and series as our cellar tileset. Its `FG_Cellar.png`
is pixel-for-pixel our `assets/cellar.png`, so it is not repeated here. Not used by the game yet: `tools/build.js` only
embeds the files it names, so nothing here reaches the page. All 16 px tiles.

| Folder | What it is |
|---|---|
| `tilesets/` | **Underground, fits as is:** Abandoned Mines, Magma Dungeon (+ Warm), Dark Castle (+ Purple, + animated torches and pools), Fortress (+ Winter), Cellar Doors (doors for our own cellar walls). **Needs toning down** (less saturation, darker): Frozen Caves. **Above ground**, for a village or overworld: Forest, Grasslands, Mountains, Houses, Village (each with seasons), Marketplace, Interior (farmhouse rooms), Grounds, Extras (round trees, bushes, flowers) |
| `objects/` | Treasure chests (small and big, closed and open), crystals in four colours, minerals, Dark Castle doors/torches/pools, trees and grass that can be cut down |
| `item-icons/` | `FG_Item_Icons.png`: mostly seed packets and harvested crops; one column of armour, boots, shields and rings |
| `crops/` | Growing stages of ~40 crops |
| `trees/` | Animated swaying trees, spring/summer/fall |
| `particles/` | Clouds, falling leaves, snowflakes |
