# Rogue Adventure World (ElvGames), kept for later

Picked file by file from ElvGames' *Rogue Adventure World*, by the same artist as our cellar. Not used by the game yet:
`tools/build.js` only embeds the files it names, so nothing here reaches the page. All 16 px tiles. `*_Animation(s)`
and `*_Doors` sheets belong to the set they are named after.

**Recoloured by us** (marked *rc* below): the licence allows edits; the original colours are in the ElvGames download.

| Set | Files | Notes |
|---|---|---|
| Crypt | `RA_Crypt` + 3 animation sheets | Grey stone, moss, blood drips, bones, spikes, candles |
| Cavern | `RA_Cavern`, `_Animations`, `_Full` | Brown rock caves and boulders |
| Hell | `RA_Hell`, `_Animations` | Dark rock, rib bones, skulls, lava |
| Graveyard | `RA_Graveyard`, `_Animations` | Gravestones, tombs, coffins |
| Ruins | `RA_Ruins`, `_Animations`, `RA_Ancient_Ruins_Animations` | Overgrown stone ruins |
| Lost City | `RA_Lost_City`, `_Animations` | Dark stone with water channels |
| Ancient *rc* | `RA_Ancient`, `_Animations`, `_Doors` | Carved brown stone; its glowing green glyphs turned dim gold |
| Beast *rc* | `RA_Beast`, `_Animation01–03`, `_Doors` | Walls of flesh, teeth and bone, toned from neon red to dark flesh |
| Temple *rc* | `RA_Temple`, `_Animation01`, `_Animations`, `_Objects` | Pillared halls; the pink stone turned warm grey, the cream stone kept |
| Sanctuary *rc* | `RA_Sanctuary` | Pale stone stairs and tiles, darkened so it does not glare |
| Pyramid *rc* | `RA_Pyramid`, `_Animations`, `_Doors` | Bright yellow toned to old sandstone; drawn in perspective |

| Village | `RA_Village_Animation01–03`, `_Animations`, `_Objects01–02` | Village objects and animated pieces (the house sheet itself was left out) |
| Jungle | `RA_Jungle`, `_Animation`, `_Animations`, `_Extras` | Jungle trees, bushes and ground |
| Wasteland | `RA_Wasteland`, `_Animation`, `_Water`, `RA_Wastelands_Animations` | Dry rocks, pools and ground |

| Item icons | `item-icons/RA_Item_Icons01`, `03` | Weapons, helmets, armour, shields, gloves and boots in several metals |

Left out after review: the pack's enemies, the ship, the village house sheet, two Beast animation sheets, the
parchment-backed icon sheet, the animated trees, and the Godot/Unity copies.
