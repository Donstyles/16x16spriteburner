# Cellar Numerals

`cellar-numerals.ttf` is a modified copy of **Grenze Black** (Copyright 2019, The Grenze Project Authors,
https://github.com/Omnibus-Type/Grenze), used for the game's numbers in the lettering trial. Changes: its level
(lining) digits are made the default in place of the old-style ones, it is cut down to the printable ASCII letters,
digits and signs (plus `·` and `×`), and it is renamed so it is not mistaken for the original. It is licensed, like
Grenze, under the SIL Open Font License 1.1: see `OFL.txt`.

Made with fontTools from the Grenze Black TTF that Google Fonts serves.
